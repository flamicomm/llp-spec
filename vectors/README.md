# Conformance vectors — `vectors/`

Every file is generated by [`../tools/build_vectors.py`](../tools/build_vectors.py)
and self-checked against [`../reference/llp_v4.py`](../reference/llp_v4.py).
Do not edit the JSON by hand: change the generator and regenerate. The case
counts live in the [main README](../README.md) (generated) and the file hashes in
[`MANIFEST.sha256`](MANIFEST.sha256).

Wire format 4.0.0: `AA 55 | LEN | CHANNEL | PAYLOAD | CRC_L | CRC_H`.

## Files

### `encode.json`

`(channel, payload)` must produce exactly the listed `frame`. The same bytes must
decode back to the same channel and payload.

Covers: an empty payload, text and command payloads, 0x00 / 0xFF / 0x55 / 0x7F
edge values, runs of `0xAA` (stuffing), `0xAA 0x55` inside the payload, a LEN of
`0xAA` (170 bytes, so the LEN field itself is stuffed), a payload whose CRC
contains `0xAA` (CRC field stuffing), and the maximum payload of 255 bytes.

### `decode.json`

Byte streams must deliver exactly the listed frames, in order.

Covers: every payload of the encode table round-tripped, two frames back to back,
garbage before the magic (ignored, never an error), `AA AA 55` as a frame start,
`AA 00` while waiting for the second magic byte, a new magic inside a frame
(resync), a bad escape, a truncated tail with no follow-up (nothing is
delivered), two frames of 255 bytes, `LEN == capacity`, channel 255, channel
`0xAA` (channel field stuffing), and an escaped magic inside the payload.

### `errors.json`

Every case must report at least one error (`result: "invalid"`), and the recovery
frame listed in `expect.frames` must still be delivered.

Covers: CRC mismatch from a flipped payload bit, from `CRC_L`, from `CRC_H`, from
all-zero CRC bytes, from a tampered `LEN` (padded so the frame stays complete) and
from a tampered `CHANNEL` (the CRC covers it). `LEN > capacity` for capacities
64, 4 and 0, including the rule that no payload byte is stored before the length
is validated. Bad escapes (`AA 01`, `AA FF`) and resync when a magic appears
where `LEN` or `CRC_H` was expected.

### `timing.json`

Gaps are expressed with `feed: [{hex, dt_ms}]` and **simulated**; nothing sleeps.
`timeout_ms` is 2000 unless noted.

Covers: a mid-frame gap greater than the timeout, a gap exactly at the limit (no
error), the limit plus one (error), a long gap before the magic and between
frames (silent, because the parser is in `WAIT_MAGIC1`), the byte after a gap
being re-examined as a magic, a timeout in each `READ_*` state, and the 16-bit
wrap: the clock crosses 65536 mid-frame and a short gap must still not time out,
while a long gap across the wrap must.

### `channels.json`

Covers: the same payload routed on channels 0, 1, 2, 3, 4, 239, 240 and 255;
channel `0xAA` (the field itself is stuffed); two identical payloads on different
channels staying distinguishable; and a chunk boundary that falls in the middle
of a frame without affecting routing or order.

### `payload.json`

The payload is opaque. Each payload here is shaped like a v3 layer chain — a
`0x00` "FinalNode", passthrough and transform headers with metadata, a reserved
`0xFF` id, truncated metadata that v3 reported as `LAYER_MALFORMED` — and must be
delivered **unchanged**, on both the encode and the decode side. This is the v4
replacement for the 55 layer vectors of v3: same transparency property, no
layer semantics.

### `streams.json`

Chunk boundaries must not change the outcome.

Covers: one byte per chunk, two-byte chunks, splits after the first magic byte,
after `LEN`, mid-payload and after `CRC_L`; three frames with mixed channels;
noise between frames; recovery after a CRC error and after a sync error; a
255-byte frame split across chunks; and garbage before the first frame.

## Result model

`result` is `valid` (accept, no error), `invalid` (must report at least one
error) or `acceptable` (implementation-defined, requires a flag). The driver
enforces the first two; see [`../docs/CONFORMANCE.md`](../docs/CONFORMANCE.md).

## Verifying a corpus you vendored

```bash
cd vectors && sha256sum -c MANIFEST.sha256
```
