# Fuzz Seeds — `fuzz-seeds/`

Deterministic AFL/libFuzzer corpus for wire format 4.0.0. Each seed is a small
byte sequence that drives a specific code path in an LLP parser.

The corpus is generated by [`../tools/generate_fuzz_seeds.py`](../tools/generate_fuzz_seeds.py)
from a curated table — not from a PRNG (which would make the corpus
irreproducible) and not from a dump of `vectors/` (a fuzzer wants boundary-hitting
inputs, not coverage duplicates). Frames are built with the reference encoder.

## Corpus structure

```
fuzz-seeds/
├── empty/          # minimal valid frames, empty payload, channel 255
├── stuffing/       # 0xAA in LEN, CHANNEL, payload and CRC (the three stuffing sites)
├── errors/         # CRC, truncation, bad escape, wrong magic
├── edge_cases/     # 255-byte payloads, all-0x00 / all-0xFF, max stuffing
└── streams/        # multi-frame, noise before/between, error recovery
```

## Generating and checking

```bash
python3 tools/generate_fuzz_seeds.py           # write the corpus
python3 tools/generate_fuzz_seeds.py --check   # CI: fail if stale or leftover
```

`--check` also reports files on disk that the generator would not produce, so a
layout change cannot leave orphan seeds behind.

## Usage with AFL

```bash
AFL_USE_ASAN=1 afl-gcc-fast your_llp_impl.c -o your_fuzzer
afl-fuzz -i fuzz-seeds/empty -o findings ./your_fuzzer
```

## Usage with libFuzzer

```bash
clang++ -fsanitize=address,fuzzer your_llp_fuzzer.cpp -o your_fuzzer
./your_fuzzer fuzz-seeds/
```
